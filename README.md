# Download Manager

Flutter project source prepared for Flutter 3.47.x.

Important:
- This archive intentionally does NOT replace root Android Gradle files.
- Run `flutter create .` in the project folder if the platform scaffold is missing.
- Then run `flutter pub get`.
- Then run `flutter run`.

The source targets Arabic RTL, Material 3, system light/dark theme, direct downloads, WebView detection, YouTube extraction, local persistence, notifications, and a video player.

Some advanced behaviors such as HLS/DASH remuxing and fully autonomous download execution after force-kill require additional platform-specific integration.
